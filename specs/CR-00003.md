## Problem

AI Dev Factory Spike needs a lightweight, dependency-free text slugification utility in the `EcKVargas/AgentFarm` repository (https://github.com/EcKVargas/AgentFarm.git) to normalize strings for identifiers, URLs, and file names. No such utility currently exists.

## Proposed Change

Add `slugify.py` containing a pure-Python function `slugify(text)` that accepts a string input, lowercases all characters, strips leading and trailing whitespace, replaces every consecutive run of non-alphanumeric characters with a single hyphen `-`, and removes any resulting leading or trailing hyphens. Add `test_slugify.py` with pytest test cases covering typical strings, edge cases, and boundary conditions. Both files must use only the Python standard library and require no network access.

## Acceptance Criteria

1. `slugify.py` exists in the repository root and defines `slugify(text: str) -> str`.
2. `slugify(" Hello World! ")` returns `"hello-world"`.
3. `slugify("foo--bar")` returns `"foo-bar"`.
4. `slugify("___leading")` returns `"leading"`.
5. `slugify("trailing___")` returns `"trailing"`.
6. `slugify("UPPER")` returns `"upper"`.
7. `slugify("a!@#b")` returns `"a-b"`.
8. `test_slugify.py` exists and contains passing pytest tests verifying criteria 2–7.
9. Both files import only from the Python standard library and perform no network I/O.
10. No additional package dependencies (e.g., no `requirements.txt` changes) are introduced.

## Out of Scope

- Unicode normalization or locale-aware transliteration.
- CLI interface or argument parsing.
- Configuration files, CI/CD pipeline changes, or documentation beyond inline docstrings.
- Performance benchmarking or fuzz testing.
